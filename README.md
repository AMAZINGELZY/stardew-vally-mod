# Enhanced Schools Mod for Stardew Valley\n\nA SMAPI mod that adds multiple school types to Stardew Valley, allowing players to enroll their children in boarding schools, arts academies, sports academies, and more.\n\n## Features\n\n- **5 School Types**: Public, Boarding, Arts, Sports, Magical\n- **Holiday System**: Spring Break, Summer Vacation, Fall Break, Winter Holiday\n- **School Terms**: 28-day academic terms matching seasons\n- **Rabbit Hole Mechanics**: Kids disappear on school days\n- **Boarding Schools**: Kids return Fridays + holidays\n- **Stat Tracking**: Grades, happiness, skills\n- **Configurable**: Costs, days, holidays\n\n## Installation\n\n1. Install [SMAPI](https://smapi.io/)\n2. Extract to `Stardew Valley/Mods/EnhancedSchoolsMod/`\n3. Run the game\n\n## School Types\n\n- **Public School** - Free\n- **Boarding School** - $5000/term, residential\n- **Arts Academy** - $2500/term, creativity focused\n- **Sports Academy** - $2500/term, athletics focused\n- **Magical Academy** - $10000/term, magic focused\n\n## Configuration\n\nEdit `config.json` to customize:\n- School costs\n- Operating days\n- Holiday schedules\n- Term length\n\n## Development\n\nBuilt with C# and SMAPI 3.13+\n\n## License\n\nMIT License\n
